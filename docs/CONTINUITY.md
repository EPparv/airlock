# Check that Airlock actually remembers

Use these steps with the installed Mac app and two connected agents. Each agent's tool results show which records it received. Its answer shows how it used them.

1. Open **Context & memory → Import context**. Choose **ChatGPT or Claude conversation** to read a local export, choose a conversation and check the individual user messages to keep. For an agent that can supply a handoff, open **Bring context from another agent** and copy the transfer request. Review the resulting memories and skills before saving.
2. In **Shared memory**, pin up to six short core records, such as communication preferences and enduring background. Set each agent's selected records and excerpt permission. Private, retired or stale records remain unavailable even if pinned. Reimporting an identical record marked `[CORE]` pins the existing record; it does not duplicate it. Manage these pins in Shared memory.
3. Start a new conversation in your connected AI. Ask a natural question requiring your background. Check **Last context request** in Airlock and inspect the AI's tool result. A connected badge alone proves no recall. Explicitly request Airlock context if the client does not call it.
4. Ask about a detailed project and its complete workflow. The AI should follow `next_query` when more results or parts are needed. Try a paraphrase as well as the project name. Inspect each item's `match_basis` for a related-term or sentence-similarity match and the response's `recall` field for the model and passage count. An empty question returns authorized context in pages.
5. Correct an imported fact in Shared memory. Ask the same question in a fresh conversation and a second authorized client. Both should use the correction on their next context request. Linked files must be edited at their original source. Already disclosed text cannot be recalled from a client's chat.
6. Retire an outdated record. It and notes derived from it should disappear from subsequent requests. Restore it to make it eligible again. New approved derived notes are also withheld when their recorded source text changes; older notes created before this release have no retrospective source hash guarantee.
7. Enable **Allow memory proposals**, then tell the AI an explicit durable preference or project update. Ask it to propose the memory. Verify it is pending and absent from active recall; approve it, include it in another scoped agent's selected records, then ask that agent about it. Airlock does not watch hidden chats or save every conversation automatically.
8. Quit and reopen Airlock and the AI. Repeat the core preference and project questions. Check the renewed context request time. Expired connections or exhausted call budgets must be renewed through the existing connection controls.

An honest pass means the client requested current context, received authorized facts, and used them correctly. Treat a plausible answer without a context request, a guessed completion, an ignored correction, or leakage outside the selected scope as a failure.

## Implementation limits

- A transfer request can retrieve information the source agent can access. A file import reads the export the owner chose. ChatGPT imports follow the active branch. Claude imports read human text blocks. Airlock skips assistant responses, hidden ChatGPT messages, tools and attachment payloads. Conversation excerpts start unchecked and retain their provenance when shared.
- The conversation picker opens JSON files up to 64 MB and submits one conversation of up to 4 MB for review. ZIP inputs have a 4 MB limit on the archive and on its selected decompressed files. Unzip larger archives and choose a conversations JSON file. Each preview supports up to 2,000 messages. Messages over 12,000 characters are skipped and counted.
- Core profile inclusion and pagination apply to automatic and scoped context requests. The legacy reviewed-excerpt mode still returns only its explicitly approved views.
- Retrieval starts with the existing local keyword ranking and aliases. It also finds related passages through two distinctive terms that occur together in an authorized direct match. On Macs with Apple's English sentence embedding available, it scores a bounded sample of up to 160 passages from eligible records that keyword search missed. Each search adds at most four related records. When the embedding is unavailable, the term-based methods continue to work.
- Filtering, grant checks and pseudonymization run before ranking. The native helper receives filtered text through a local pipe and retains no vector index. Relevance is approximate. Sampling, the English model and the similarity threshold can all contribute to missed results. Project names and an empty query remain available for a broader lookup.
- Paging is bound to the requesting connection and its current authorized content; pages expire after 30 minutes and fail if content or permission changes. The AI must repeat the original query after such a change.
- New memory proposals need owner approval. Approved additions do not silently broaden another scoped agent's access.
- MCP instructions request context refresh but cannot enforce it inside another vendor's app. The visible request timestamp measures a successful retrieval, not whether the host model used it correctly.

Run the focused regressions with `python -m pytest -q tests/test_continuity.py tests/test_local_recall.py`. The native model smoke test requires macOS with Apple's English model available. The other checks cover reviewed export imports, grant-isolated related-term search, encrypted restart, two clients, core recall on unrelated queries, full workflows, pagination, scope isolation, private records, corrections, derived-note staleness, owner-only controls, duplicate imports, revision changes and cursor expiry/revocation.
