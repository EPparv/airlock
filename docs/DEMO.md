## 90-second script

1. **0–15 seconds:** Show the four fictional records. “Using a new agent shouldn't mean re-uploading your whole life. Airlock keeps one local library and gives each agent only the context you choose.”
2. **15–30 seconds:** Read as Coding agent, then Writing agent. Point out the different allowed records. Try the financial record and show the denial.
3. **30–50 seconds:** Writing agent proposes a follow-up memory. Show it pending, then accept it as owner. Give Coding agent the new memory and its parent records, save, and read again. The new note is now reusable.
4. **50–70 seconds:** Stage a private task. Show the input review and explain the separate result approval. If inference is unavailable, show the blocked state honestly. Only include a generated response if a real configured provider actually returned it.
5. **70–90 seconds:** Revoke the writing connection and show the next request failing. “The optional NEAR route adds confidential remote inference with verification and encryption. That integration is implemented, but this release has not completed a live NEAR validation.”
