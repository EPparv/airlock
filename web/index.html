A LOCAL WALKTHROUGH

Try the whole
memory loop.

Encrypted storage, selected access and owner approvals. The basic walkthrough needs no AI key.

  1. Download and extract.

    Use a new folder. This preview is separate from an existing Airlock installation.

  2. Open the local control panel.

    Run bash Run-Airlock.command in the extracted folder. First launch installs the Python dependencies. Keep Terminal open.

  3. Choose, propose, approve.

    Compare the two simulated agents’ views, propose a memory, approve it, then give the other agent access. Revoke access and try again.

What is still experimental?

This is an alpha source release, not a notarized Mac installer. Native IronClaw integration and live NEAR inference remain unverified. The regular Mac app depends on companion source not included here; the isolated walkthrough is self-contained. Full setup and validation limits are included in SHARED_MEMORY.md.
