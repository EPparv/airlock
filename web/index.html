Getting started

Unzip the download, move Airlock to Applications, and open it. First launch needs an internet connection. You can try the sample workspace before adding any personal notes.

If macOS blocks the first launch

This release is ad-hoc signed and hasn’t been notarized by Apple. If you trust the download, try opening Airlock once, then go to System Settings, Privacy & Security, and choose Open Anyway.

What happens when I share a note?

Airlock can return an excerpt from an allowed record when the connected agent asks for it. That excerpt then reaches the agent. You can revoke access to stop future requests. The agent may retain what it already received.
